# Getting help

- **How do I…?** The [README](README.md) covers installing, mock servers, the command line and AI
  agents; [`docs/`](docs/) has a guide for every part.
- **Questions and ideas:** [GitHub Discussions](https://github.com/LibreGuild/twinbase/discussions).
  Q&A for questions, Ideas for suggestions, Show and tell for what you built with TwinBase.
- **Something is broken:** [open a bug report](https://github.com/LibreGuild/twinbase/issues/new?template=bug_report.yml).
  Search the existing issues first; a 👍 on an existing one helps us prioritise.
- **Security problem:** report it privately; see [SECURITY.md](SECURITY.md).

TwinBase is maintained by volunteers, so answers can take a few days. Clear steps to reproduce (a
seed script, the SQL, the driver you use) get the fastest help.
